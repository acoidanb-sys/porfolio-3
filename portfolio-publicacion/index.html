                lógica técnica y herramientas
              

                
lógica técnica / creative coding2026

                

                  
01input
Pointer Events captura coordenadas, duración y velocidad tanto con ratón como con interacción táctil.

                  
02heat field
cada muestra deposita energía en una matriz bidimensional; la intensidad se calcula según velocidad y permanencia.

                  
03render
Canvas traduce los valores acumulados a una escala térmica de púrpura, rojo, naranja y amarillo.

                  
04decay
un bucle de animación aplica difusión y pérdida progresiva de temperatura hasta limpiar la superficie.

la experiencia comienza con una forma abstracta de 26.000 partículas que respira, se pliega y altera su densidad con el sonido. el visitante puede orbitarla, pausar el movimiento y sustituirla por un modelo .ply propio, además de usar una pista de audio o el micrófono.

              estudio interactivo original / prototipo vivo
            


            

              

                webgl / sound / generative matter
                
campo gaussiano — estudio audio-reactivo

                
la forma inicial aparece como una reliquia inestable entre volumen, niebla y residuo, pero puede reemplazarse desde el propio visor. graves, medios y agudos gobiernan distintas capas de torsión, desplazamiento, foco y color.

              

              

                
              

              

                raw webgl / fft adaptativo / pausa / carga .ply / audio o micrófono
                
              

              
            


            

              sistema generativo y ficha técnica
              

                
render
webgl y glsl propios, point sprites gaussianas, mezcla alfa, paleta personalizable y campo procedural o modelo .ply

                
audio
fft de 1024 muestras, normalización adaptativa, envolventes attack / release y detección de golpes y transitorios

                
mapping
graves: expansión; medios: torsión; agudos: fragmentación y color; golpes: onda expansiva y destello

                
interaction
órbita, zoom, pausa, cuatro colores editables y paletas preparadas, carga o arrastre .ply, respuesta audio, deformación, foco, curvatura, voxelización, grano y captura png

                
performance
26.000 partículas iniciales; importación limitada a 60.000 puntos en escritorio y 20.000 en móvil, dpr limitado y reduced motion

                
reference
arquitectura inspirada por Gausseous de Quixbrics (MIT); dirección visual y motor provisional reconstruidos para este portfolio

                
import
archivos .ply ASCII o binary little-endian, con centrado, escala y reducción de puntos automáticos
